# StatPulse Analytics redesign plan

## Current app inventory

### Routes

- `/` homepage
- `/services` and `/services/[slug]`
- `/solutions` and `/solutions/[slug]`
- `/portfolio` and `/portfolio/[slug]`
- `/dashboard-demo`
- `/about`
- `/contact`
- `/privacy`
- `/admin/login` and `/admin/leads`
- `/api/leads` and `/api/admin/leads/[id]`
- `/robots.txt`, `/sitemap.xml`, Open Graph image, and not-found page

### Shared components

- Layout: navbar, footer, site shell, analytics consent, JSON-LD
- UI: logo, button link, eyebrow, section header, icon tile, accordion
- Content: homepage, dashboard, chart, portfolio filter, contact and admin components

## Design direction

- Use deep navy, warm orange, white, and light grey as the core palette.
- Use Plus Jakarta Sans for headings and Inter for body copy.
- Use a 1,200px content width, an 8px spacing scale, pill buttons, rounded cards, and quiet shadows.
- Keep the site plain-spoken, with short headlines and clear next actions.
- Use original product visuals, code-built dashboard mockups, and clearly marked placeholder imagery where a supplied image is still needed.

## Image plan

- Original AI-created laptop dashboard visual for the homepage hero.
- Code-built dashboard previews for service and live-demo areas.
- Tall industry image cards use marked placeholders until real licensed photographs are supplied.
- Use the supplied founder portrait only when an existing founder image position is confirmed.

## Delivery phases

### Phase A — design system and shell

Create shared colour, type, spacing, card, button, header, footer, and CTA styles. Update global navigation and footer structure.

### Phase B — homepage

Rebuild the homepage with hero, trust placeholder, testimonial placeholder, services, industry sections, process, confirmed-facts band, sample dashboard, calculator, tools, resources, pricing, FAQ, and final CTA.

### Phase C — inner pages

Bring services, solutions, portfolio, dashboard, about, contact, privacy, and terms into the shared visual system. Add insights and starter articles.

### Phase D — quality pass

Check responsive behaviour, focus states, semantic structure, metadata, structured data, sitemap, and placeholder coverage.
